# ✈️ Jornada Viagens
 Landing page responsiva desenvolvida para uma agência de viagens moderna, focada em apresentar destinos turísticos e pacotes exclusivos. Este projeto foi consolidado como o desafio final da trilha de Programação Web da Alura.
O projeto simula a interface de uma agência real, focando em alta fidelidade visual, navegação fluida e semântica HTML, transformando um protótipo de alta fidelidade em uma aplicação funcional.
 
﻿# 🎯 Jornada Viagens

Este projeto foi desenvolvido com o objetivo de:

- Fidelidade ao Design: Traduzir layouts complexos do Figma para código real.
- Dominar Flexbox e CSS Grid: Estruturar o posicionamento de elementos de forma moderna.
- Implementar Design Responsivo: Garantir a experiência do usuário em dispositivos móveis (Mobile First).
- Praticar HTML Semântico: Melhorar SEO e acessibilidade da página.
- Organização de Estilos: Utilizar variáveis CSS para manter a identidade visual do projeto.

# 🎨 Design & Prototipagem
Para o desenvolvimento desta landing page, utilizei o Figma como ferramenta de suporte, onde realizei:

- Extração de Assets: Coleta de ícones, imagens e exportação de elementos gráficos.
- Inspeção de Propriedades: Análise de espaçamentos (paddings/margins), cores em Hexadecimal e tipografia.
- Medição de Componentes: Garantia de que o código refletisse exatamente as proporções pensadas no design original.

# 🔧 Funcionalidades

- Hero Section: Banner de impacto com call-to-action (CTA).
- Cards de Destinos: Exibição de pacotes com efeitos de transição CSS.
- Seção de Depoimentos: Prova social organizada em grid responsivo.
- Formulário de Newsletter: Estrutura pronta para captura de leads.
- Rodapé Estruturado: Links de navegação e ícones de redes sociais.

🛠 Tecnologias Utilizadas

- HTML5: Estruturação semântica.
- CSS3: Estilização avançada, variáveis e animações.
- Figma: Ferramenta de inspeção de design e extração de assets.
- Google Fonts: Tipografia personalizada definida no protótipo.

🧠 Conceitos Aplicados

- Hand-off de Design: Processo de leitura de protótipos para codificação.
- Mobile First: Priorização da experiência em telas menores.
- Acessibilidade: Uso de tags <header>, <main>, <section> e atributos alt.
- Clean Code: Código indentado e modularizado para fácil manutenção.
